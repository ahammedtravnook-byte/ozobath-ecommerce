MongoDB Atlas — Free Cloud Database
Create and connect your database first — everything else depends on this
🍃
Create a Free MongoDB Atlas Account
  1. 1
    Go to MongoDB Atlas and sign up

    Create a free account — you can sign up with Google for speed.

    🔗 https://www.mongodb.com/cloud/atlas/register
  2. 2
    Create a New Project

    After login, click "New Project" → Name it ozobath → Click "Create Project".

  3. 3
    Build a Free Cluster

    Click "Build a Database" → Select "FREE" (M0 Sandbox) → Choose provider: AWS → Region: Mumbai (ap-south-1) for India → Click "Create".

  4. 4
    Create a Database User

    A popup will appear. Set a username (e.g., ozobath-user) and a strong password. Save this password — you'll need it. Click "Create User".

  5. 5
    Add IP Whitelist: Allow All

    On the same setup screen, under "Where would you like to connect from?" → Click "Add My Current IP" THEN also add 0.0.0.0/0 (allows all IPs — required for Render.com). Click "Finish and Close".

  6. 6
    Get Your Connection String

    In the Atlas dashboard, click "Connect" on your cluster → "Connect your application" → Select Node.js, version 4.1 or later → Copy the connection string. It looks like:

    mongodb+srv://ozobath-user:YOUR_PASSWORD@cluster0.xxxxx.mongodb.net/ozobath?retryWrites=true&w=majority

    ⚠️ Replace <password> with your actual password, and add ozobath as the database name before the ?.

  7. 7
    Seed Super Admin Account

    After deploying the backend, run this command once to create the admin user:

    cd apps/server
node src/seeds/superAdmin.seed.js

Render — Free Backend Hosting
Deploys the Node.js + Express API server (apps/server)
🚀
Deploy the Backend API to Render
  1. 1
    Create a Render account

    Sign up with GitHub — this is the easiest way to connect your code repository.

    🔗 https://render.com
  2. 2
    Push code to GitHub first

    Make sure the project is pushed to a GitHub repository. If not, create a new repo at github.com/new and push: 

    git remote add origin https://github.com/YOUR_USERNAME/ozobath-ecommerce.git
git push -u origin main
  3. 3
    Create a New Web Service on Render

    In Render dashboard → Click "New +" → "Web Service" → Connect your GitHub account → Select the ozobath-ecommerce repository.

  4. 4
    Configure the service settings

    Fill in these exact values:

    FieldValue
    Nameozobath-api
    Root Directoryapps/server
    EnvironmentNode
    Build Commandnpm install
    Start Commandnode server.js
    PlanFree
  5. 5
    Add Environment Variables

    Before clicking "Create Web Service", scroll down to "Environment Variables". Add ALL the variables from Section 9 of this guide. You MUST add these before deployment or the app will crash.

  6. 6
    Click "Create Web Service" and wait

    Render will build and deploy your server. This takes 3–5 minutes. Once deployed, you'll get a URL like:

    https://ozobath-api.onrender.com

    Save this URL — you'll need it when deploying the frontend apps.

⚠️ Important: After getting your Render backend URL, go back and update the CLIENT_URL and ADMIN_URL environment variables to your actual Vercel URLs (you'll get those in the next section).

Vercel — Free Frontend Hosting
Deploy both the Customer Website (React) and Admin Panel (Vue)
🛍️
Deploy: Customer Website (apps/client)
  1. 1
    Go to Vercel and sign in with GitHub
    🔗 https://vercel.com/signup
  2. 2
    Import the repository

    Click "Add New → Project" → Import ozobath-ecommerce from GitHub.

  3. 3
    Configure project settings
    FieldValue
    Root Directoryapps/client
    Framework PresetVite
    Build Commandnpm run build
    Output Directorydist
  4. 4
    Add Environment Variable

    In the "Environment Variables" section add:

    VITE_API_URL = https://ozobath-api.onrender.com/api/v1
  5. 5
    Click Deploy

    Wait 2 minutes. You'll get a URL like ozobath.vercel.app

⚙️
Deploy: Admin Panel (apps/admin)
  1. 1
    In Vercel, add a second project

    Click "Add New → Project" again → Import the same repository.

  2. 2
    Configure project settings
    FieldValue
    Root Directoryapps/admin
    Framework PresetVite
    Build Commandnpm run build
    Output Directorydist
  3. 3
    Add Environment Variable
    VITE_API_URL = https://ozobath-api.onrender.com/api/v1
  4. 4
    Click Deploy

    You'll get a URL like ozobath-admin.vercel.app

🔄
After Both Vercel Deployments — Update Render

Go back to Render → Your ozobath-api service → Environment → Update these two variables:

CLIENT_URL=https://ozobath.vercel.app
ADMIN_URL=https://ozobath-admin.vercel.app

Then click "Save Changes" — Render will automatically redeploy the backend with the updated CORS settings.

Razorpay — Payment Gateway
Accepts UPI, Cards, Net Banking, Wallets in India — client must create this account
🔴 Client Action Required: The business owner must create the Razorpay account using their business details. Payments will go directly to their bank account. This cannot be done by the developer on their behalf.
💳
Phase 1: Create Razorpay Account & Get Test Keys
  1. 1
    Sign up on Razorpay

    Create an account using the business email address.

    🔗 https://dashboard.razorpay.com/signup
  2. 2
    Get Test API Keys (for testing)

    After login → Go to Settings → API Keys → Click "Generate Test Key". You'll see:

    Key ID: rzp_test_XXXXXXXXXXXXXXXX
    Key Secret: XXXXXXXXXXXXXXXXXXXXXXXX

    ⚠️ Copy the Key Secret immediately — it's shown only once.

  3. 3
    Add test keys to environment variables

    Add these to your Render environment variables (see Section 9):

    RAZORPAY_KEY_ID = rzp_test_XXXXXXXXXXXXXXXX
    RAZORPAY_KEY_SECRET = XXXXXXXXXXXXXXXXXXXXXXXX
  4. 4
    Test payments with test card numbers

    Use these Razorpay test credentials when placing test orders:

    MethodValue
    Card Number4111 1111 1111 1111
    ExpiryAny future date (e.g., 12/26)
    CVVAny 3 digits (e.g., 123)
    OTP1234
✅
Phase 2: KYC Verification & Go Live (Receive Real Payments)
  1. 1
    Complete Business Activation (KYC)

    In Razorpay Dashboard → Click "Activate Account" or go to Account & Settings → Business Details. Fill in:

    • Business Type (Proprietorship / Private Limited etc.)
    • Business Category (Retail - Home Improvement)
    • Business PAN / GST Number
    • Bank Account details for settlements
    • Address proof documents
  2. 2
    Wait for Razorpay approval

    Approval typically takes 1–3 business days after document submission. You'll receive an email confirmation.

  3. 3
    Generate Live API Keys

    After approval → Settings → API Keys → Switch to "Live Mode" toggle → Click "Generate Live Key".

    Key ID: rzp_live_XXXXXXXXXXXXXXXX
    Key Secret: XXXXXXXXXXXXXXXXXXXXXXXX
  4. 4
    Update live keys in Render

    Replace test keys with live keys in Render environment variables. The server will automatically start accepting real payments.

ℹ️ Settlement Schedule: Razorpay settles payments to your bank account on a T+2 (2 business days) cycle by default. You can see all transactions in the Razorpay dashboard under Transactions.

Shiprocket — Shipping Management
Multi-carrier shipping, order tracking, AWB generation — client must create this account
🔴 Client Action Required: The business owner must create a Shiprocket account. Shipping contracts and COD settlements are tied to the business details. The developer cannot create this account.
📦
Create Shiprocket Account & Get API Credentials
  1. 1
    Sign up on Shiprocket

    Register with the business email. You can choose the free plan to start.

    🔗 https://app.shiprocket.in/register
  2. 2
    Complete business profile

    After login → Settings → Company Details → Fill in:

    • Company Name, Address, Pincode
    • GSTIN (if applicable)
    • Pickup Location details
    • Bank account for COD remittances
  3. 3
    Create a Pickup Location

    Go to Settings → Pickup Addresses → Add the warehouse/office address where couriers will come to pick up orders. Note down the pickup pincode.

  4. 4
    Get API Credentials

    The OZOBATH backend uses Shiprocket's email + password for API authentication (no separate API key needed). Simply use the registered Shiprocket account email and password:

    SHIPROCKET_EMAIL = your-registered@email.com
    SHIPROCKET_PASSWORD = your-shiprocket-password
    PICKUP_PINCODE = 560001 (replace with your actual pincode)
  5. 5
    Set up Webhook (for automatic order status updates)

    In Shiprocket → Settings → API → Add webhook URL:

    https://ozobath-api.onrender.com/api/v1/shipping/webhook

    This URL receives automatic updates when a shipment is picked up, in transit, delivered, etc. — updating your order status in real-time.

Gmail SMTP — Free Email Service
For order confirmations, password resets, and notification emails
📧
Set Up Gmail App Password (2FA Required)
  1. 1
    Enable 2-Factor Authentication on your Gmail
    🔗 https://myaccount.google.com/security → "2-Step Verification" → Turn On
  2. 2
    Generate an App Password
    🔗 https://myaccount.google.com/apppasswords

    Select app: "Mail" → Select device: "Other (Custom name)" → Type "OZOBATH Server" → Click "Generate".

    You'll get a 16-character password like: abcd efgh ijkl mnop → Remove spaces: abcdefghijklmnop

  3. 3
    Add to environment variables
    SMTP_HOST = smtp.gmail.com
    SMTP_PORT = 587
    SMTP_USER = your-gmail@gmail.com
    SMTP_PASS = abcdefghijklmnop
    EMAIL_FROM = noreply@ozobath.com
ℹ️ Gmail SMTP free tier allows up to 500 emails/day. For high-volume production use, consider upgrading to SendGrid (100 emails/day free) or Resend (3,000 emails/month free).

Environment Variables — Master Reference
All variables that must be added to Render before the backend goes live
🔴 Critical: These environment variables MUST be set in Render before deployment. Missing variables will cause the app to crash. Do NOT commit the actual values to GitHub.
⚙️
Render Backend — Environment Variables (apps/server) 
# ─── APP ────────────────────────────────────────────────────
NODE_ENV=production
PORT=5000
CLIENT_URL=https://ozobath.vercel.app         # Your Vercel client URL
ADMIN_URL=https://ozobath-admin.vercel.app    # Your Vercel admin URL

# ─── MONGODB ─────────────────────────────────────────────────
MONGODB_URI=mongodb+srv://ozobath-user:PASSWORD@cluster0.xxxxx.mongodb.net/ozobath?retryWrites=true&w=majority

# ─── JWT SECRETS (generate random strings — use a password manager) ──
JWT_ACCESS_SECRET=your_super_secret_access_key_min_32_characters
JWT_REFRESH_SECRET=your_super_secret_refresh_key_min_32_characters
JWT_ACCESS_EXPIRY=15m
JWT_REFRESH_EXPIRY=7d

# ─── CLOUDINARY ──────────────────────────────────────────────
CLOUDINARY_CLOUD_NAME=your_cloud_name
CLOUDINARY_API_KEY=123456789012345
CLOUDINARY_API_SECRET=xxxxxxxxxxxxxxxxxxxxxxxx

# ─── RAZORPAY ────────────────────────────────────────────────
RAZORPAY_KEY_ID=rzp_test_XXXXXXXXXXXXXXXX      # Change to rzp_live_ when going live
RAZORPAY_KEY_SECRET=XXXXXXXXXXXXXXXXXXXXXXXX

# ─── EMAIL (GMAIL SMTP) ───────────────────────────────────────
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=youremail@gmail.com
SMTP_PASS=abcdefghijklmnop                   # 16-char Gmail App Password (no spaces)
EMAIL_FROM=noreply@ozobath.com

# ─── SHIPROCKET ──────────────────────────────────────────────
SHIPROCKET_EMAIL=your-shiprocket-email@example.com
SHIPROCKET_PASSWORD=your-shiprocket-password
PICKUP_PINCODE=560001                         # Your warehouse pincode

# ─── SUPER ADMIN (used only for first seed) ──────────────────
SUPER_ADMIN_NAME=OZOBATH Admin
SUPER_ADMIN_EMAIL=admin@ozobath.com
SUPER_ADMIN_PASSWORD=OzoBath@2024!
SUPER_ADMIN_PHONE=9999999999

# ─── OPTIONAL (Gemini AI Chatbot) ────────────────────────────
GEMINI_API_KEY=your_gemini_api_key            # Optional - leave blank to disable chatbot

Vercel Frontend Variables (Both apps/client and apps/admin)

🔑
How to Generate Secure JWT Secrets

Run this command in your terminal to generate a secure random string for JWT secrets:

# Option 1: Node.js (run anywhere)
node -e "console.log(require('crypto').randomBytes(64).toString('hex'))"

# Option 2: Online tool
https://generate-secret.vercel.app/64

Generate TWO different secrets — one for JWT_ACCESS_SECRET and one for JWT_REFRESH_SECRET.

⚠️
Important Security Notes
  • 🔐 Never commit .env files or API keys to GitHub. Always use Render/Vercel's environment variable settings.
  • 🔑 Change the default SUPER_ADMIN_PASSWORD immediately after first login.
  • 💳 Use Razorpay test keys during development. Only switch to live keys when the site is ready for real customers.
  • 🔒 JWT secrets must be at least 32 characters and truly random. Never use obvious strings like "secret123".
  • 🌍 MongoDB Atlas IP whitelist 0.0.0.0/0 is fine for Render (dynamic IPs), but in future consider using VPC peering for higher security.
